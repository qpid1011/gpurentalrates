3. SXM / NVLink vs PCIe Architecture Selection Guide:
RTX 5090 (32 GB GDDR7, 1.79 TB/s, PCIe Gen5) and RTX 4090 (24 GB GDDR6X, 1.01 TB/s, PCIe Gen4) omit NVLink/P2P high-speed fabric, so multi-GPU all-reduce traverses host PCIe. Use 1x–4x RTX 5090/4090 instances for quantized LLM inference (AWQ/GGUF/FP8), diffusion/video rendering, LoRA adapters, and embarrassedly parallel batch workers.
